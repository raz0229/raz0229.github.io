About Me

👤 Who is raz0229?

I got into programming the way a lot of people my age did, messing with a computer I didn't fully understand until things started making sense. Since then I've picked up a bit of everything: building websites, wrapping APIs, writing browser extensions, automating boring stuff with bots, and dabbling in mobile apps. I wouldn't call myself an expert in any one corner of the stack. I just enjoy figuring out how to make something work and then making it work a little better.

Most of what I build starts from a small annoyance or a "wouldn't it be nice if..." moment. A university portal that looked outdated became a Chrome extension used by hundreds of my classmates. Wanting a clean way to search the Quran turned into an API published on RapidAPI. A CraftingInterpreters challenge turned into an actual little programming language with a logo and an AUR package, which is probably more effort than it deserved, but here we are.

Outside of paid gigs, I like tinkering with Linux (Arch, obviously), ricing my desktop far more than necessary, and occasionally going down a rabbit hole of writing something in C just to remember how memory works.

🗃 More From the Repo Pile

🧪 PavaLang

A dynamically-typed, tree-walking interpreter written entirely in Java, variables, user-defined functions with default arguments, closures, control flow, arrays, modules, and a set of built-in functions, all following the classic CraftingInterpreters challenge. Even ships as an actual installable package for Arch Linux (AUR) and Snap. Yes, I made a whole programming language for fun. GitHub →

🐚 Badmash Shell

A minimal Unix-like shell written in C from scratch: command execution, pipelines, I/O redirection, background processes, command history and auto-completion, all built on top of a custom lexer and fork()/execvp() execution engine. GitHub →

🧩 Prompt-GPT Extension

A Chrome extension that turns any text field on the web into a ChatGPT prompt box, complete with speaking and listening abilities so you can talk to it directly. GitHub →

🤖 Python Instagram Command Bot

A Selenium-driven Instagram bot with a dozen chat commands, translation, Wikipedia lookups, quotes, image search and more, plus a separate chat mode for automatic DM replies. An extended fork of an earlier WhatsApp bot I wrote. GitHub →

🖥 .dotfiles

My personal Arch Linux + i3wm configuration, because apparently rebuilding your own desktop environment from scratch is a completely normal way to spend a weekend. GitHub →
